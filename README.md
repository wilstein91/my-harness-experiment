# My Harness Experiment

이 저장소는 노드 실습 중 `discount.py` 버그 수정 요청에서 사용자 요청 포맷만 바꾸어 비교한 보고서입니다. 노드 마지막의 전체 프로젝트 제출물은 아닙니다.

## 가설

같은 Codex 환경, 같은 시작 파일, 같은 테스트를 사용할 때 search-replace 요청은 자유 텍스트 요청보다 더 정확하게 수정 대상을 지정할 수 있다.

## 사전 판정 기준

조건마다 한 번만 실행하는 파일럿입니다. 한 조건만 첫 시도에서 올바르게 수정하고 테스트까지 통과하면 해당 조건을 지지하는 신호로 기록합니다. 두 조건 모두 통과하거나 모두 실패하면 어느 포맷이 더 낫다는 결론은 내리지 않습니다.

## 실행 조건

- 고정: Codex 실행 환경, 시작 파일, 테스트, 작업
- 조작: 사용자 요청 포맷(자유 텍스트 / search-replace)
- 측정: 패치 내용, 제공 테스트 통과 여부, 재시도 횟수
- 제한: 조건별 1회 파일럿이므로 일반화하지 않습니다.

## 결과

두 조건 모두 동일한 테스트 1개를 첫 시도에 통과했습니다. 사전 판정 기준상 어느 포맷이 더 낫다고 결론 내리지 않습니다. 자세한 내용은 `experiment-01.md`와 `traces/`를 확인하세요.
